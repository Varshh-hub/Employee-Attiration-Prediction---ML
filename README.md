# Employee Attrition Prediction

A **Machine Learning classification project** that predicts whether an employee is likely to leave an organization based on employee-related features. The project includes data preprocessing, exploratory data analysis, feature preparation, model training, hyperparameter optimization, and comprehensive model evaluation.

---


## Project Overview

Employee attrition is an important challenge for organizations because losing employees can increase recruitment costs, reduce productivity, and affect team performance. This project applies Machine Learning techniques to identify patterns in employee data and predict potential employee attrition.

The main objective is to build a reliable classification model that can help organizations understand employee attrition patterns and identify employees who may be at higher risk of leaving.

---

## Dataset

The dataset contains employee-related information used to train and evaluate the Machine Learning model.

* **Training records:** 59,598
* **Testing records:** 14,900
* **Features:** 24
* **Missing values:** None
* **Duplicate records:** None

The features contain different employee-related attributes that can be used to understand factors associated with employee attrition.

---

## Machine Learning Workflow

The project follows a complete Machine Learning workflow:

**Data Collection → Data Preprocessing → Exploratory Data Analysis → Feature Engineering → Model Training → Hyperparameter Tuning → Model Evaluation → Prediction**

A **Random Forest Classifier** is used as the primary Machine Learning model.

Random Forest combines multiple decision trees to produce a more robust classification model. It is suitable for this problem because it can capture complex relationships between different employee attributes and the target variable.

---

### Hyperparameter Optimization

Hyperparameter tuning is performed to improve model performance and identify a suitable combination of parameters for the Random Forest model.

The tuning process helps reduce the risk of using a poorly configured model and improves its ability to generalize to unseen data.

---

## Model Evaluation

The trained model is evaluated using multiple classification metrics:

* **Accuracy**
* **Precision**
* **Recall**
* **F1-Score**
* **ROC-AUC**
* **Confusion Matrix**

Using multiple evaluation metrics provides a better understanding of the model's performance rather than relying only on accuracy.

---

## Objective

The goal of this project is to demonstrate how Machine Learning can be applied to **employee attrition prediction** and how a classification model can be developed, optimized, and evaluated using a real-world dataset.

---

## Conclusion

This project demonstrates an end-to-end Machine Learning approach for predicting employee attrition. By combining data preprocessing, exploratory analysis, Random Forest classification, hyperparameter tuning, and multiple evaluation metrics, the project provides a structured approach to building an employee attrition prediction system.
